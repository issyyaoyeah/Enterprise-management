差异化战略（高差异定位战略）
第6章 业务层战略 P148–175 【2016笔试·简答】
›
核心定义
差异化战略是指在广泛或狭窄市场上，通过建立和发挥差异优势，向对价格不敏感但对产品性能与质量有特殊要求的顾客提供差异化产品/服务，以获得高于行业平均收益的战略。
理论框架

实现差异优势的五大关键领域：

领域核心内容
市场与消费者研究深度洞察顾客特殊需求
创造新的营销概念品牌定位、价值传递
全面质量管理确保产品/服务的卓越性
产品/服务研究开发持续创新，维持差异壁垒
发挥人才管理体制吸引并留住创造差异的核心人才
答题步骤

给出概念定义：广泛/狭窄市场 + 差异优势 + 价格不敏感顾客 + 高于平均收益

阐述核心内容：五大关键领域 + 价值活动体系 + 战略取舍

分析优势：进入壁垒高 + 顾客忠诚 + 五力恶化时仍可盈利

说明风险：定价过高 / 模仿 / 扩张弱化差异 / 难以覆盖广泛市场

结合案例：苹果（品牌生态溢价）或世纪金榜（七审七校）

核心关键词
差异优势价格不敏感高于平均收益 进入壁垒顾客忠诚五大关键领域 战略取舍价值活动
经典案例
苹果公司：极致产品设计 + 生态系统 + 品牌溢价，目标顾客对价格不敏感，持续获得超额利润。
世纪金榜："七审七校"审校制度与杂志化编排，实施教辅行业差异化战略。
总结
差异化战略的本质在于"取舍与专注"——向特定顾客提供竞争对手无法复制的独特价值，核心是在价值链关键环节建立难以模仿的差异优势。
02
成本领先战略（低成本定位战略）
第6章 业务层战略 P148–168 【2019笔试·简答】
›
核心定义
低成本定位战略是指在广泛或狭窄市场上，通过建立和发挥各种成本优势，以标准化产品服务价格敏感型大众顾客，力求占据低成本竞争位置，并获得高于行业平均收益的战略。
理论框架

建立成本优势的四大领域：

领域核心措施
①生产与物流高效率大规模低成本的生产与物流设施
②营销/研发/服务将相关成本降至最低
③采购成本规模采购 + 纵向整合
④运营与行政职能制+集权化管理，严格控制开支
答题步骤

定义：价格敏感型市场 + 成本优势 + 高于平均收益

四大领域：生产物流 / 营销研发 / 采购 / 运营行政

优势：最强进入壁垒 + 讨价还价 + 抗压 + 对抗替代品

风险：忽视顾客需求 / 技术进步 / 易被模仿

案例：沃尔玛或万和集团

核心关键词
成本优势价格敏感型规模效应 效率优先标准化产品四大领域 进入壁垒全价值链成本
经典案例
沃尔玛：大规模采购、高效物流与严格成本控制，全球零售业成本领先典范。
万和集团：在燃气热水器行业瞄准万家乐，采取低成本定位战略。
总结
成本领先战略的核心逻辑是"规模效应 + 效率优先"，须在保证基本产品质量的前提下，系统压缩全价值链成本，同时保持顾客导向与创新能力以防御竞争风险。
03
平衡计分卡（BSC）
第11章 战略实施的管理与控制 P348–354 【2016笔试·简答】
›
核心定义
平衡计分卡（BSC）是由卡普兰和诺顿提出的战略绩效管理工具，通过财务、客户、内部流程、学习与成长四个维度全面评估企业绩效，将战略目标转化为可操作的绩效衡量系统，克服了单纯依赖财务指标的短视问题。
理论框架（四维度）
维度视角核心问题
财务股东视角如何看待股东？
客户市场视角如何被客户认知？
内部流程运营视角哪些流程必须做好？
学习与成长发展视角如何持续改进？

因果链逻辑：学习与成长 → 内部流程改善 → 客户满意 → 财务成功

答题步骤

定义：卡普兰诺顿 + 四维度 + 战略目标转化

四维度：财务/客户/内部流程/学习与成长，说明因果链

优势：四对平衡（财务vs非财务、短期vs长期）+ 战略落地

局限：设计复杂、因果关系难量化、形式主义风险

案例：美孚石油公司（Mobil）

核心关键词
四维度因果链战略落地 财务视角客户视角内部流程 学习与成长四对平衡绩效衡量
经典案例
美孚石油（Mobil）：通过BSC将"成为最盈利的石油公司"战略分解为四维度具体指标，实现战略成功落地的经典案例。
总结
BSC的核心价值在于"把战略翻译成行动"——用四维度绩效指标体系构建战略实施的闭环管理，是战略控制与战略实施的重要工具。

企业文化
第11章 战略实施的管理与控制 P328–342 【2018笔试·论述】
›
核心定义
企业文化是指企业全体员工在长期的生产经营活动中形成的共同价值观念、行为准则、思维方式和管理理念的总和，是企业独特的精神财富。（沙因：人工制品→价值观→基本假设 三层次）
理论框架（五大功能）
功能作用说明
导向功能引导员工行为方向
凝聚功能增强组织向心力
激励功能激发员工内在动力
约束功能形成无形行为规范
辐射功能对外传播品牌与形象
答题步骤

定义：沙因三层次 + 共同价值观、行为准则

五大功能：导向/凝聚/激励/约束/辐射，逐一说明

优势：强文化支持战略实施，降低协调成本

风险：文化惰性 / 变革代价高 / 并购文化冲突

案例：海底捞极致服务文化 / 华为狼性文化

核心关键词
五大功能沙因三层次文化与战略匹配 价值观行为准则文化惰性 文化吃掉战略软基础
经典案例
海底捞："极致服务"文化支撑差异化战略，员工主人翁精神体现激励功能。
华为："狼性文化"有效支撑国际化扩张战略的实施。
总结
企业文化是战略实施的"软基础"——文化与战略一致时产生强大执行力；文化与战略不匹配时，文化往往比战略更强大，"文化吃掉战略"。

波特五力模型
第3章 外部环境分析（行业环境） P60–75 【2016笔试·简答】
›
核心定义
波特五力模型是由迈克尔·波特提出的行业竞争结构分析框架，通过五种竞争力量判断行业吸引力与企业竞争地位，是外部行业环境分析的核心工具。
理论框架（五力）
力量方向核心要素
①现有竞争者横向行业集中度、产品同质化程度、退出壁垒
②潜在进入者上方威胁进入壁垒高低（规模/品牌/资本）
③替代品跨行业替代品性价比、转换成本
④买方议价能力下游买方集中度、差异化程度、后向整合能力
⑤供应商议价能力上游供应商集中度、前向整合能力
答题步骤

定义：波特提出 + 五种力量 + 判断行业吸引力

逐一说明五力：名称 + 方向 + 影响因素

优势：系统性识别竞争压力 + 战略定位依据

局限：静态分析 + 数字经济时代局限

案例：新能源汽车行业五力分析

核心关键词
五种竞争力量行业吸引力进入壁垒 议价能力替代品威胁行业平均利润 战略定位竞争格局
经典案例
新能源汽车：现有竞争激烈（比亚迪/特斯拉）；新进入者众多（小米/华为）；买方议价强（价格战）；供应商（锂矿/芯片）议价能力强——成为核心制约。
总结
五力模型帮助企业回答"行业值不值得进入、如何在行业中定位"——分析时要识别当前最强的一两股力量，有针对性地构建竞争防御。

PESTEL分析框架
第3章 外部环境分析（宏观环境） P50–62 【2018笔试·简答】
›
核心定义
PESTEL分析是对企业宏观外部环境六个维度进行系统扫描的框架，用于识别企业面临的宏观机会与威胁，是战略分析的第一步，为SWOT中的"外部机会/威胁"提供依据。
理论框架（六维度）
维度英文核心要素
政治Political政策、法规、政府稳定性
经济EconomicGDP增速、利率、汇率、通胀
社会Social人口结构、文化观念、生活方式
技术Technological技术创新、R&D投入、数字化
环境Environmental气候、环保法规、碳排放
法律Legal劳动法、知识产权、行业规制
答题步骤

定义：宏观环境六维度 + 识别机会与威胁 + 战略分析第一步

六维度：逐一说明P/E/S/T/E/L的含义与核心要素

优势：系统性扫描 + 防止忽略重要变化

局限：维度交叉 + 宏观难转化 + 过时风险

案例：比亚迪新能源 / PESTEL多维利好叠加

核心关键词
宏观环境六维度机会与威胁 环境扫描战略分析起点与五力配合
经典案例
比亚迪：P=政府补贴；E=油价上涨；T=电池技术突破；En=碳中和政策——多维度叠加形成历史性战略机遇。
总结
PESTEL是战略分析的"环境扫描器"，通常与五力模型（行业层面）和SWOT（综合层面）配合使用，形成完整的外部环境分析体系。
07
钱德勒命题：结构追随战略
第11章 战略实施的管理与控制 P302–310 【2019笔试·简答】【复试高频】
›
核心定义
钱德勒通过对杜邦、通用汽车等四家大企业的历史研究，提出著名命题："结构追随战略（Structure Follows Strategy）"——企业组织结构必须随战略变化而调整，否则组织结构将成为战略实施的障碍。
理论框架（四阶段演变）
战略阶段对应结构
单一产品/市场简单结构
单一产品扩大市场职能制（U型）
多产品多市场事业部制（M型）
全球化多元化矩阵制/网络组织
答题步骤

定义：钱德勒 + 四企业研究 + 结构追随战略

四阶段：单一→简单结构→多元→事业部制等演变

意义：战略实施的组织设计依据

反向补充：资源基础观——组织能力也可引导战略

案例：通用汽车斯隆改革（职能制→事业部制）

核心关键词
结构追随战略四阶段演变事业部制 职能制战略实施骨骼路径依赖
经典案例
通用汽车（斯隆）：从单一汽车扩展为多品牌后，将公司从职能制改造为事业部制（雪佛兰、别克、凯迪拉克各自独立核算），是"结构追随战略"的经典实证。
总结
钱德勒命题的核心启示：战略转型不能只"换战略、不换结构"——组织结构是战略实施的"骨骼"，战略变了，骨骼不变，新战略就无法有效落地。
08
SWOT分析
第5章 战略问题的确认与基本战略选择 P135–148 【2017笔试·简答】
›
核心定义
SWOT分析是将企业内部的优势（S）、劣势（W）与外部环境的机会（O）、威胁（T）进行综合对比分析，以识别战略问题并形成战略选择方案的框架工具。
理论框架（四种战略组合）
组合策略方向逻辑
SO增长型战略扩张利用优势抓住机会
WO扭转型战略补短克服劣势利用机会
ST多元化战略防御用优势应对威胁
WT防御型战略收缩减少劣势回避威胁
答题步骤

定义：内部S/W + 外部O/T + 综合对比分析

四组合：SO/WO/ST/WT + 各自战略方向

优势：连接内外部分析的桥梁 + 操作简便

局限：主观性强 + 静态 + 只提供方向不能确定最优

案例：华为2019年应对实体清单制裁（ST战略）

核心关键词
SO/WO/ST/WT战略问题识别内外部综合 优势劣势机会威胁战略选择桥梁
经典案例
华为2019：S=技术积累与海思芯片；W=供应链依赖美国；O=国内政策支持与5G机遇；T=技术封锁威胁。→ST战略：用技术优势反制威胁，加速国产替代。
总结
SWOT的价值不在于列清单，而在于识别战略问题——"最关键的匹配与错位在哪里"，帮助管理者聚焦于最重要的战略选择。

多元化战略
第7章 公司层战略 P175–210 【2016笔试·案例】【2021笔试·简答】
›
核心定义
多元化战略是指企业向原有业务以外的新行业或新市场扩张，涉及多个不同业务领域的公司层战略。核心动机是利用范围经济、分散风险或追求协同效应。
理论框架（四种类型）
类型定义特点
相关多元化新业务与原有业务存在技术/市场/资源联系协同效应强，风险相对低
非相关多元化新业务与原有业务无明显联系分散风险，管理难度高
约束型所有业务共享核心资源/能力最典型的相关多元化
关联型业务间两两关联，但非共同核心介于相关与非相关之间
答题步骤

定义：新行业/新市场 + 范围经济/分散风险/协同

四种类型：相关/非相关/约束型/关联型，逐一区分

优势：范围经济 + 分散风险 + 扩展市场边界

风险：多元化折价 + 资源分散 + 协同难以实现

案例：GE过度多元化 vs 腾讯相关多元化

核心关键词
相关/非相关多元化范围经济协同效应 多元化折价核心专长约束型/关联型
经典案例
GE：非相关多元化典范，过度多元化导致管理失控，最终大幅剥离业务回归专业化。
腾讯：以社交为核心向游戏、金融、广告等相关领域扩张——成功的相关多元化。
总结
多元化战略关键问题是"新业务与原有能力的关联程度"——相关多元化要确保协同效应真实存在；非相关多元化须具备强大的集团管理能力，否则"多元化是战略毒药"。
10
资源基础观（RBV）
第4章 内部环境分析 P99–112 【2022笔试·简答】
›
核心定义
资源基础观（RBV）由彭罗斯奠基、巴尼系统化，认为企业持续竞争优势来源在于其拥有的有价值、稀缺、难以模仿、不可替代的资源与能力（VRIN标准），而非外部市场定位。
理论框架（资源分类 + VRIN）
VRIN含义说明
V - Valuable有价值顾客认可，能创造价值
R - Rare稀缺竞争对手难以拥有
I - Imperfectly imitable难以模仿历史积累/综合性/文化嵌入
N - Non-substitutable不可替代无其他能力可替代

资源分类：人力资源 / 有形资源（设备/资金）/ 无形资源（品牌/技术/文化）

答题步骤

定义：彭罗斯/巴尼 + 内部资源能力 + VRIN四标准

VRIN：逐一解释四项标准含义

优势：揭示绩效差异内在原因 + 无形资源战略价值

局限：静态分析 + 难精确评估 + 忽视外部环境

案例：茅台（地理/品牌/工艺满足VRIN全部标准）

核心关键词
VRIN四标准持续竞争优势内部资源能力 彭罗斯/巴尼无形资源动态能力补充
经典案例
茅台：稀缺的地理环境（赤水河水质/气候）+ 历史品牌（难以模仿）+ 特殊酿造工艺（不可替代）——完全符合VRIN四项标准，构成持续竞争优势。
总结
RBV的核心逻辑是"企业是独特资源的集合体"——战略制定应从内部出发，识别、建立、保持VRIN资源，并将其与外部机会匹配，才能形成可持续的竞争优势。

核心定义
蓝海战略由钱·金与莫博涅提出，是指企业超越竞争、开创无竞争的全新市场空间的战略。核心是价值创新——同时追求差异化与低成本，重构行业边界，使竞争变得无关紧要。
理论框架（"剔减增创"四动作）

答题步骤

优势：开创新市场 + 差异化与低成本双赢

风险：蓝海快速变红海 + 执行难度高

核心关键词

总结
蓝海战略精髓是"价值创新"——不是比竞争对手做得更好，而是从根本上改变顾客价值标准，使现有竞争变得无意义。

动态能力理论

理论框架（四象限）
象限名称特征战略选择

›
核心定义

三大优点四大局限性
①降低交易成本①可能牺牲规模经济
②增强市场影响力②增加代理成本与控制成本
③防止技术和信息外泄③退出成本高，灵活性差

四大局限：规模经济牺牲/代理成本/退出壁垒/创新降低

趋势：虚拟整合取代实体纵向一体化

苹果/富士康：虚拟整合——苹果不拥有生产线，但通过供应链管理实现更高控制效率。
总结
纵向一体化本质是"内部化市场交易"——须权衡内部化带来的代理成本上升与灵活性下降；数字化时代，虚拟整合往往优于实体纵向一体化。

阿里巴巴：分析（持续识别互联网机会）→制定（"让天下没有难做的生意"）→实施（多次组织架构调整）→控制（动态评估各业务进展）——经典战略管理过程全周期案例。
总结
战略管理过程是企业"从哪里来、去哪里、怎么去、走对没有"四个问题的系统回答；四阶段不是直线，而是持续迭代的闭环；战略实施往往比制定更难，是战略成功的真正瓶颈。

战略钟模型
第6章 业务层战略 P163–178 【2021笔试·简答】
›
核心定义
战略钟模型（鲍曼）以感知价值（纵轴）和价格（横轴）为坐标，描绘出企业可能的八种竞争定位，形似时钟表盘，帮助企业分析哪些定位可持续，哪些是竞争陷阱。
理论框架（八种战略位置）
位置名称价格感知价值可持续性
1无附加价值低低仅限细分市场
2低价策略低中✅ 可持续（成本领先支撑）
3混合策略中低中高✅ 可持续（最佳性价比）
4差异化策略中高高✅ 可持续（品牌溢价）
5聚焦差异化高高（特定）✅ 可持续（细分定位）
6高价低值高低❌ 不可持续
7/8失败区高标准/低❌ 不可持续
核心关键词
感知价值/价格混合策略竞争失败区 八种定位时钟表盘鲍曼
经典案例
小米：典型混合策略（位置3）——高性价比，以规模效应控制成本。
苹果：聚焦差异化（位置5）——高价+高感知价值，专注高端市场。
总结
战略钟核心贡献：揭示"价格—价值感知"关系——可持续定位：低价（成本领先）/高值（差异化）/两者兼有（混合）；高价低值区永远是竞争陷阱。

商业模式画布
第6章 业务层战略 P170–178 【2024笔试·简答·九大模块】
›
核心定义
商业模式画布（奥斯特瓦德）是将企业商业模式可视化为九大模块的战略分析工具，系统描述企业如何创造价值、传递价值和获取价值。
理论框架（九大模块）
模块英文核心问题助记
客户细分CS为谁创造价值？客
价值主张VP提供什么独特价值？值
渠道通路CH如何触达客户？渠
客户关系CR如何维系客户？系
收入来源RS如何获得收入？收
核心资源KR需要哪些关键资源？资
关键业务KA必须做哪些核心活动？业
重要合作KP谁是关键合作伙伴？伙
成本结构CS主要成本来自哪里？本

助记口诀：「客值渠系收，资业伙本」

核心关键词
九大模块客值渠系收资业伙本价值主张 轻资产平台价值创造与获取商业模式创新
经典案例
Airbnb：客户细分（旅行者+房东）→价值主张（低成本本地住宿）→核心资源（房源数据库+平台）→收入（佣金）——轻资产 vs 传统酒店重资产的根本差异。
总结
商业模式画布价值在于梳理"价值如何在企业与客户之间流动"——九大模块构成相互依存的有机系统，任何一模块的创新都可能触发整体商业模式重构。

集中化战略（聚焦战略）
第6章 业务层战略 P164–168 【复试面试高频·定位战略完整体系】
›
核心定义
集中化战略（聚焦战略）是波特基本定位战略第三种类型，指企业集中资源专注于特定细分市场、特定顾客群体或特定地域，在该狭窄市场上建立成本优势或差异优势。分为低成本聚焦和高差异聚焦两种。
理论框架（适用条件 + 两种子类型）
子类型特征代表企业
低成本聚焦在细分市场以低价获胜春秋航空（专注价格敏感旅客）
高差异聚焦在细分市场以高价值获胜保时捷（专注高端跑车细分）

适用条件：①细分市场规模足够 ②主流对手忽视该市场 ③资源不足在宽泛市场竞争 ④细分市场有独特需求

核心关键词
细分市场低成本聚焦/高差异聚焦四种适用条件 以小搏大深度护城河波特第三战略
经典案例
西南航空：聚焦价格敏感短途旅客，取消餐食、旅行社预定——典型低成本聚焦。
红星宣纸：专注高端书画纸市场，传统工艺+地理标志保护——典型高差异聚焦。
总结
聚焦战略本质是"把有限资源集中到最有胜算的战场"——不求全行业制胜，在特定细分市场建立深不可撼的竞争优势；成功关键是选对细分市场，持续深化护城河。

战略方向四种类型
第5章 战略问题的确认与基本战略选择 P147–149 【2025笔试关联】【面试高频】
›
核心定义
战略方向是企业基于战略承诺，确定的特定发展阶段（一般3–5年）的基本发展路径。教材将其划分为四种基本类型，构成2×2矩阵（行业维度×市场维度）。
理论框架（四种战略方向）
行业\市场单一市场多个市场
单一行业行业/市场集中战略市场多元化战略（国际化）
多个行业行业多元化战略行业与市场多元化战略

以发展态势划分：增长型 / 稳定型 / 防御型 / 收缩型

核心关键词
行业/市场集中四种方向矩阵增长/防御/收缩 2×2矩阵战略选择起点
经典案例
阿里巴巴：集中战略→行业多元化→行业与市场多元化，清晰展示战略方向演进。
格力：长期坚持行业/市场集中战略，以专注取得全球空调第一。
总结
战略方向是"选择在哪块战场竞争"的根本决策——集中还是多元、本国还是跨国、增长还是收缩，直接决定资源配置优先顺序。

战略承诺
第5章 战略问题的确认与基本战略选择 P133–148 【面试高频·宗旨愿景战略意图】【2025笔试关联】
›
核心定义
战略承诺是企业基于资源和能力，考虑外部环境及未来变化趋势，为实现长期战略目标而向利益相关者做出的长期经营承诺。是战略内容体系中时间跨度最长、影响最广的战略要素。
理论框架（五项核心内容）
内容说明表述形式
企业经营目的（使命）企业存在的根本理由宗旨陈述
愿景企业期望成为什么样子长期价值取向+生动描述
战略意图雄心勃勃的宏伟梦想简洁口号（不超过三句话）
经营理念经营的根本指导思想价值观陈述
核心价值观指导行为的最根本准则简洁价值词汇
核心关键词
使命/愿景/战略意图利益相关者战略灵魂 核心价值观经营理念时间跨度最长
经典案例
阿里巴巴：宗旨"让天下没有难做的生意"（经营目的）；愿景"构建未来商务生态系统，持续发展102年"（挑战性+价值追求）。承诺始终未变，是成功战略内核。
总结
战略承诺是战略的"灵魂"——回答"我们是谁、为何存在、向何处去"；是战略制定的逻辑起点，也是战略控制的终极评判标准。

多元化程度评估与控制
第7章 公司层战略 P196–220 【2016笔试·案例】【2021笔试·多元化风险】
›
核心定义
多元化程度评估与控制要求企业在推进多元化战略时，在正确动机、恰当时机、合适方式、合理速度、适度程度五个维度进行系统控制，防止过度多元化折价。
理论框架（五维推进策略）
维度核心要点典型陷阱
正确动机增强竞争优势，非管理者私利盲目追风口
恰当时机主业成熟期后再多元化过早多元化
合适方式新建/并购/战略联盟权衡过度依赖并购
合理速度控制负债率，留足资源激进同时进入多行业
适度程度必须"有所不为"多元化折价、管理失控
核心关键词
五维控制多元化折价有所不为 合理速度主业成熟期负债率控制
经典案例
TCL（反面）："多元化时准备不足、资源分散、战线拉得过长"——过早多元化的教训。
本田（正面）："成功一个再进入一个新行业"——控制多元化速度的经典。
总结
多元化程度控制核心是"有所不为，才能有所为"——相关多元化优先，不相关多元化须具备强大集团管理能力。

国际化动因与风险
第8章 国际化战略 P210–235 【2024笔试·新能源国际化案例】【面试高频】
›
核心定义
国际化动因是驱动企业将经营活动扩展至本国以外的内外部原因，从主要推动因素和主要限制因素两个维度分析，同时面临多种特有风险需系统识别与管控。
理论框架（动因 + 风险）
国际化动因（四类）典型案例
市场寻求：突破本国市场饱和华为进入发展中国家
效率寻求：利用海外低成本要素富士康在越南建厂
资源寻求：获取稀缺资源（矿产/技术/品牌）吉利收购沃尔沃
战略资产寻求：获取全球战略布局所需资源联想收购IBM PC业务
国际化主要风险（四类）
政治风险：政策变化、贸易壁垒、地缘政治
汇率风险：本币升值、外汇损失
文化风险：管理理念冲突、本地化失败
管理风险：跨国协调难、总部控制弱化
核心关键词
四类动因四类风险市场/效率/资源/战略资产 政治/汇率/文化/管理走出去管得好
经典案例
比亚迪出海：市场寻求+效率寻求；面临政治风险（欧盟反补贴调查）、文化风险（品牌认知差距）。
TCL早期失败：低估欧洲文化差异与品牌壁垒——文化风险典型案例。
总结
国际化动因决定"为何出海"，风险识别决定"能否活下来"——成功的国际化战略须在市场机会、资源能力和风险承受之间找到平衡点。

企业并购与PMI整合
第9章 战略联盟、并购与重组 P255–275 【2019面试·并购人力整合】【2024笔试·国际化案例关联】
›
核心定义
企业并购（M&A）是指通过购买股权或资产将目标企业纳入控制范围的战略行为。并购后整合（PMI）是决定并购成败的关键阶段，涉及战略、组织、文化、人力四个维度的整合。
理论框架（PMI四维整合）
整合维度核心任务常见风险
战略整合明确并购后战略定位与协同目标协同效应高估，方向不清
组织整合设计新组织结构，明确汇报关系重叠部门裁撤冲突
文化整合融合两种企业文化，建立共同价值观并购失败首要原因
人力整合关键人才留存、激励重构核心人才流失
核心关键词
PMI四维整合文化整合是关键用资本换时间 并购溢价协同效应核心人才留存
经典案例
吉利×沃尔沃（成功）：战略整合（品牌独立）+文化整合（尊重欧洲管理）+人力整合（保留工程师）——PMI经典成功案例。
明基×西门子（失败）：低估文化差异，整合成本远超预期，以16亿亏损终止。
总结
并购核心逻辑是"用资本换时间"；PMI整合才是真正的战场——文化整合是最难也是最关键的维度；避免急于"强制同化"破坏被并购企业的核心价值。

五种组织结构类型
第11章 战略实施的管理与控制 P304–320 【2025笔试关联】【面试高频·结构追随战略】
›
核心定义
组织结构是企业实施战略的"骨骼"。依据钱德勒命题，蓝海林教材详述了五种主要组织结构及其与战略的匹配关系。
理论框架（五种结构对比）
结构类型最佳匹配战略优点缺点
简单结构创业期·单一产品灵活快速高度依赖创始人
职能制（U型）单一业务扩张专业化高，规模经济跨部门协调难
事业部制（M型）相关/非相关多元化分权灵活，激励充分事业部本位主义
矩阵制复杂项目型资源共享，跨职能协调双重领导冲突
网络组织动态竞争·轻资产高灵活性，快速响应协调难，核心能力外流
核心关键词
五种结构事业部制（M型）结构追随战略 职能制（U型）矩阵制网络组织
经典案例
通用汽车（斯隆）：1920年代从职能制→事业部制改革（别克/雪佛兰/凯迪拉克独立核算），历史性经典案例。
腾讯：职能制→事业群制（BG制）→部分功能独立子公司，随多元化持续演进。
总结
五种结构构成从简单到复杂的演进谱系——核心原则是"结构服务于战略"；实践中最忌讳"战略已变，结构未动"，是战略实施失败的最常见原因。

战略领导力六大职责
第11章 战略实施的管理与控制 P320–328 【面试高频必备】【2024笔试·AI管理变革论述关联】
›
核心定义
战略领导力是战略领导者通过远见与决策引导企业实现战略目标的能力。蓝海林教材将其总结为六大职责，构成战略实施"软性力量"的核心框架。
理论框架（六大职责）
序号职责核心内涵典型案例
①确定战略方向制定长期愿景与使命，提供行动方向任正非"全球领先电信"愿景
②开发和保护核心能力识别、培育、保护VRIN资源，防止外流华为坚守通信技术研发
③建立和维持有效文化塑造与战略一致的价值观，文化是"看不见的控制系统"海底捞以人为本文化
④强调道德行为以自身示范诚信，建立合规氛围巴菲特"声誉是无价之宝"
⑤建立组织控制系统设计战略实施监控与纠偏机制BSC四维度战略控制
⑥培育人力资本识别、吸引、培养、留住关键人才谷歌"20%自由时间"

助记口诀：「定核文道控人」

答题步骤

定义：战略领导者 + CEO/高层 + 六大职责框架

六大职责：逐一说明①确定方向②核心能力③文化④道德⑤控制⑥人才，每项给出要点

整合价值：六大职责相互支撑，形成战略领导力闭环

案例：乔布斯（六大职责全面体现）

核心关键词
六大职责定核文道控人战略实施第一要素 战略方向核心能力组织文化 道德行为控制系统人力资本
经典案例
乔布斯全面体现六大职责：
①确定方向（"为大众提供最好的技术"）→②保护核心能力（芯片自研、iOS封闭）→③建立文化（极致产品主义）→④道德行为（隐私保护原则）→⑤控制系统（产品发布里程碑管控）→⑥培育人才（吸引顶级工程师）
总结
战略领导力是战略实施成功的"第一要素"——方向引领行动，文化保障执行，控制纠正偏差，人才持续赋能；六大职责缺少任何一个，战略实施都将出现系统性漏洞。
