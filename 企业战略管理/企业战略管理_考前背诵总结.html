01
差异化战略 ★★★★★
第6章 P148-175｜2016/2017/2021/2022/2023/2024 出现6次

定义：广泛/狭窄市场 + 差异优势 + 价格不敏感顾客 + 高于行业平均收益

五大领域：

  • ① 市场与消费者研究 — 深度洞察
  • ② 新营销概念 — 品牌定位
  • ③ 全面质量管理 — 产品卓越
  • ④ 产品/服务研发 — 持续创新
  • ⑤ 人才管理体制 — 核心人才

风险：定价过高 / 被模仿 / 扩张弱化差异 / 难覆盖广泛市场

案例：苹果（生态溢价）/ 世纪金榜（七审七校）

02
成本领先战略 ★★★★★
第6章 P148-168｜2016/2019/2024 出现3次

定义：价格敏感型市场 + 成本优势 + 标准化产品 + 高于平均收益

四大领域：

  • ① 生产与物流 — 高效率低成本
  • ② 营销/研发/服务 — 降至最低
  • ③ 采购成本 — 规模采购+纵向整合
  • ④ 运营与行政 — 集权化严控

风险：忽视顾客需求 / 技术进步 / 易被模仿

案例：沃尔玛 / 万和集团

03
平衡计分卡 BSC ★★★★★
第11章 P348-354｜2016笔试 + 高频面试

定义：卡普兰&诺顿 · 四维度战略绩效管理工具 · 战略目标→可操作绩效系统

财务 → 客户 → 内部流程 → 学习与成长
股东视角 → 市场视角 → 运营视角 → 发展视角

因果链：学习与成长 → 流程改善 → 客户满意 → 财务成功

四对平衡：财务/非财务 · 短期/长期 · 内部/外部 · 结果/过程

案例：美孚石油（Mobil）战略落地

04
企业文化 ★★★★★
第11章 P328-342｜2018笔试论述 + 2021面试

定义：全体员工共同的价值观念、行为准则、思维方式和管理理念总和

沙因三层次：人工制品（外显）→ 价值观 → 基本假设（核心）

五大功能：导向 · 凝聚 · 激励 · 约束 · 辐射

强文化：支持战略 降低协调成本 ｜ 文化惰性：变革代价高

⚠️ "文化吃掉战略" — 文化与战略不匹配时文化更强大

案例：海底捞极致服务 / 华为狼性文化

05
波特五力模型 ★★★★★
第3章 P60-75｜2016笔试 + 历年面试

定义：迈克尔·波特 · 行业竞争结构分析框架 · 判断行业吸引力

力量方向核心影响因素
①现有竞争者横向集中度 / 产品同质化 / 退出壁垒
②潜在进入者上方进入壁垒（规模/品牌/资本）
③替代品威胁跨行业性价比 / 转换成本
④买方议价下游集中度 / 差异化 / 后向整合
⑤供应商议价上游集中度 / 前向整合

局限：静态分析 / 数字经济时代平台颠覆五力逻辑

案例：新能源汽车 — 供应商（锂/芯片）议价力最强

06
PESTEL分析框架 ★★★★★
第3章 P50-62｜2018笔试 · 前5年高频直考

定义：宏观外部环境六维度系统扫描 · 识别机会与威胁 · 战略分析第一步

P=政治(政策法规) · E=经济(GDP/利率/汇率)
S=社会(人口/文化) · T=技术(创新/数字化)
E=环境(气候/碳排放) · L=法律(劳动法/知产)

配合：PESTEL（宏观）→ 五力（行业）→ SWOT（综合）

案例：比亚迪 — P补贴+E油价+T电池+En碳中和 多维利好叠加

07
结构追随战略（钱德勒命题）★★★★★
第11章 P302-310｜2019笔试 + 复试高频

核心命题："Structure Follows Strategy" — 组织结构必须随战略变化而调整

单一产品 → 简单结构
单一产品扩大市场 → 职能制（U型）
多产品多市场 → 事业部制（M型）
全球化多元化 → 矩阵制 / 网络组织

研究基础：杜邦 / 通用汽车 / 西尔斯 / 标准石油 四企业历史研究

案例：通用汽车（斯隆）职能制→事业部制改革

08
SWOT分析 ★★★★★
第5章 P135-148｜2017/2021/2023 出现3次

定义：S优势 + W劣势（内部）× O机会 + T威胁（外部）综合分析框架

组合策略名方向逻辑
SO增长型扩张用优势抓机会
WO扭转型补短克服劣势利用机会
ST多元化/防御防御用优势应对威胁
WT防御型收缩减少劣势回避威胁

局限：主观性强 / 静态 / 只提供方向不能确定最优

案例：华为2019 — ST战略：技术优势反制封锁

09
多元化战略 ★★★★★
第7章 P175-210｜2016案例/2018/2019/2021 出现5次

定义：向原有业务以外新行业/新市场扩张 · 核心动机：范围经济+分散风险+协同效应

类型特点
相关多元化技术/市场/资源联系 · 协同强 · 风险低
非相关多元化无明显联系 · 分散风险 · 管理难
约束型所有业务共享核心资源/能力
关联型业务两两关联但非共同核心

风险：多元化折价 / 资源分散 / 协同难以实现

案例：GE过度多元化（失败）/ 腾讯相关多元化（成功）

10
资源基础观 RBV ★★★★★
第4章 P99-112｜2022笔试 · 2016/2020/2022/2023 共5次

定义：彭罗斯奠基/巴尼系统化 · 持续竞争优势源于内部VRIN资源，非外部市场定位

V = Valuable（有价值）
R = Rare（稀缺）
I = Imperfectly Imitable（难以模仿）
N = Non-substitutable（不可替代）

资源分类：有形资源（设备/资金）/ 无形资源（品牌/技术/文化）/ 人力资源

局限：静态分析 / 难精确评估 / 忽视外部环境 → 动态能力理论补充

案例：茅台（地理+品牌+工艺 = VRIN全满足）

11
战略实施体系 ★★★★★
第10-11章｜2016/2018/2020/2022/2025×2 出现6次（最高频）

核心内容：组织结构设计 + 战略领导力 + 企业文化 + BSC绩效控制

分析 → 制定 → 实施（最难） → 控制
组织/领导力/文化 是战略实施"软基础"

战略实施特点：①复杂性 ②长期性 ③综合性 ④人员的关键性

实施障碍：文化惰性 / 组织结构不匹配 / 领导力不足 / 资源不足

关键工具：BSC + 五种组织结构 + 六大战略领导力职责

12
内部环境分析体系 ★★★★★
第4章｜2016/2020/2022/2023×2 出现5次

分析框架体系：

资源分类
→
价值链分析
→
核心专长
→
动态能力
→
RBV

价值链：基本活动（输制输营服）× 支持活动（基人技采）

核心专长：VRIN + 三发挥路径（规模/范围/降低交易成本）

动态能力：四层体系中最高级 — 应变/创新/重组

📌 中频考点（★★★★ 重要）2-3次 · 重点掌握
13
蓝海战略 ★★★★
第6章 P168-178｜2017/2022 · 近5年高频

定义：钱·金&莫博涅 · 开创无竞争全新市场 · 核心：价值创新（差异化+低成本）

四动作框架（剔减增创）：

剔除↓↓（行业理所当然要素）
减少↓（大幅低于行业标准）
增加↑（大幅高于行业标准）
创造↑↑（行业从未提供的要素）

红海vs蓝海：争夺现有需求 vs 创造并开发新需求

案例：太阳马戏团 / 老年人手机

14
动态能力理论 ★★★★
第4章 P105-108｜2023笔试/2019面试 · 命题升级

四层能力体系（从低到高）：

第1层：管理能力（计划/组织/领导/控制）门槛
第2层：经营能力（营销/财务/研发/供应链）门槛
第3层：整合能力（内外部资源整合协调）关键
第4层：动态能力（应变/创新/重组）最高级

价值：弥补RBV静态局限 · 超竞争环境下持续创造新优势

案例：英特尔 — 存储器→微处理器转型成功

15
BCG矩阵（波士顿矩阵）★★★★
第7章 P196-205｜2019笔试 · 高频案例工具

两轴：相对市场份额（横轴）× 业务增长率（纵轴）

象限名称特征策略
高增长+高份额⭐明星高投入高收益继续投资
高增长+低份额❓问题需现金前途不明选择性投资
低增长+高份额🐄现金牛产生大量现金收割利润
低增长+低份额🐕瘦狗收益低前途暗淡撤资剥离

理想路径：问题→明星→现金牛 ｜ 案例：本田 摩托车→汽车

16
纵向一体化战略 ★★★★
第7章 P183-204｜2018笔试简答

定义：整合上游（后向）或下游（前向）价值活动 · 本质：内部化市场交易

✅ 三大优点

  • 降低交易成本
  • 增强市场影响力
  • 防止信息技术外泄

❌ 四大局限

  • 牺牲规模经济
  • 增加代理成本
  • 退出成本高灵活性差
  • 降低技术创新能力

案例：美的（完整产业链）/ 苹果（虚拟整合）

17
国际化战略三种类型 ★★★★
第8章 P210-235｜2020/2023/2024 出现3次

核心矛盾：全球整合（效率）vs 本地响应（适应）

类型整合压力本地响应代表
多国化低高雀巢
全球化高低英特尔
跨国化★最难高高丰田/华为

国际化动因：市场寻求 / 效率寻求 / 资源寻求 / 战略资产寻求

国际化风险：政治风险 / 汇率风险 / 文化风险 / 管理风险

18
战略联盟 ★★★★
第9章 P237-255｜2018面试/2023笔试 · 隔年出现

定义：独立企业间 · 契约/股权安排 · 保持独立法人 · 中间组织形态（市场←联盟→并购）

五大动机：①获取外部资源 ②降低成本与风险 ③进入新市场 ④建立行业标准 ⑤学习竞争对手

治理类型：股权式（合资·最紧密）/ 非股权式（契约）/ 松散合作

核心风险：机会主义行为 + 核心能力外泄

案例：上汽×通用（股权式）· "以市场换技术"警示

19
战略控制四种类型 ★★★★
第11章 P342-354｜斯曾德尔&霍弗 · 复试高频
类型监控对象触发条件
前提控制⭐战略制定的环境假设持续性监控
战略监控可能影响战略的宽泛信号持续扫描
特别预警控制突发事件与危机重大事件触发
实施控制⭐战略实施里程碑进展按阶段评估

口诀：前监特实 · 前提最早 · 实施最常用 · 特别预警最紧急

案例：柯达 — 前提控制缺失（胶片假设失效），错失数码转型

20
五种组织结构类型 ★★★★
第11章 P304-320｜2025笔试关联 · 钱德勒命题延伸
结构类型最佳匹配战略核心优缺
简单结构创业期·单一产品灵活↑ / 依赖创始人
职能制（U型）单一业务扩张专业化↑ / 跨部协调难
事业部制（M型）相关/非相关多元化分权灵活↑ / 本位主义
矩阵制复杂项目型资源共享↑ / 双重领导
网络组织动态竞争·轻资产高灵活↑ / 能力外流风险

案例：通用汽车 职能制→事业部制改革（斯隆改革）

21
战略领导力六大职责 ★★★★
第11章 P320-328｜面试高频 · 2024笔试论述关联
口诀：「定核文道控人」
①定战略方向 ②开发保护核心能力
③建立维持有效文化 ④强调道德行为
⑤建立组织控制系统 ⑥培育人力资本

每项要点：

  • ① 制定长期愿景与使命，引导行动方向
  • ② 识别培育保护VRIN资源，防止外流
  • ③ 塑造与战略一致的价值观（"看不见的控制系统"）
  • ④ 以自身示范诚信，建立合规氛围
  • ⑤ 设计监控与纠偏机制（BSC）
  • ⑥ 吸引培养留住关键人才

案例：乔布斯（六大职责全面体现经典案例）

22
战略管理过程 ★★★★
第1-2章 P1-30｜2025笔试 + 历年面试

四阶段：

战略分析（外部+内部）
→ 战略制定（承诺+目标+方向+选择）
→ 战略实施（组织+文化+领导力）⭐最难
→ 战略控制（监控+评估+纠正）

配套工具：分析用PESTEL/五力/SWOT/价值链 · 实施用BSC/组织结构/文化

特点：动态迭代闭环 · 非线性 · 实施是最大瓶颈

📎 低频考点（★★★ 常考）了解掌握
23
战略钟模型（鲍曼）★★★
第6章 P163-178｜2021笔试

坐标：感知价值（纵）× 价格（横）· 八种竞争定位

可持续定位：低价（2）/ 混合（3）/ 差异化（4）/ 聚焦差异（5）

陷阱区：高价低值（6/7/8）→ 永远不可持续

案例：小米→混合策略（3）/ 苹果→聚焦差异（5）

24
商业模式画布（九大模块）★★★
第6章 P170-178｜2024笔试考九大模块
口诀：「客值渠系收 · 资业伙本」
客户细分(CS) · 价值主张(VP)⭐核心 · 渠道通路(CH)
客户关系(CR) · 收入来源(RS) · 核心资源(KR)
关键业务(KA) · 重要合作(KP) · 成本结构(CS)

案例：Airbnb — 轻资产（房源数据库+平台）vs 传统酒店重资产

25
集中化战略（聚焦战略）★★★
第6章 P164-168｜面试高频 · 波特三大战略完整体系

定义：集中资源专注特定细分市场，建立成本优势或差异优势 · 波特第三基本战略

两种子类型：低成本聚焦（春秋航空）/ 高差异聚焦（保时捷）

适用条件：①细分市场规模足够 ②主流对手忽视 ③资源不足 ④细分市场有独特需求

26
战略方向四种类型 ★★★
第5章 P147-149｜2025笔试关联 · 面试高频
行业\市场单一市场多个市场
单一行业集中战略市场多元化（国际化）
多个行业行业多元化行业+市场多元化

发展态势：增长型 / 稳定型 / 防御型 / 收缩型

案例：格力→长期集中战略 / 阿里→逐步多元化

27
战略承诺（使命·愿景·战略意图）★★★
第5章 P133-148｜面试高频 · 逻辑起点

定义：企业向利益相关者做出的长期经营承诺 · 时间跨度最长的战略要素

五项核心内容：
企业经营目的（使命）/ 愿景 / 战略意图
经营理念 / 核心价值观

战略意图：雄心勃勃的宏伟梦想 · 简洁口号（不超过三句话）

案例：阿里 "让天下没有难做的生意" = 经营目的（使命）

28
企业并购与PMI整合 ★★★
第9章 P255-275｜2019面试/2024案例关联

并购类型：横向（同行）/ 纵向（上下游）/ 混合（跨行业）

PMI四维整合：战略整合 → 组织整合 → 文化整合（最难/最关键） → 人力整合
