绩效管理
🔴 高频 ★★★★★
真题年份
2016面2018笔2019面2023笔2025笔
概念框架
  • 绩效 = 行为 + 结果（Brumbrach，二维模型）
  • 任务绩效（核心工作）vs 关系绩效（OCB）vs 适应性绩效
  • 绩效管理 ≠ 绩效评价；管理是持续过程，评价是一个环节
3大目的
战略目的 → 管理目的 → 开发目的
绩效管理循环（PDCA）
计划→ 辅导→ 评价→ 反馈
评价方法对比
方法核心特点
图尺度法最简单；主观性强
行为锚定法(BARS)行为 → 等级锚定；信度高
关键事件法记录典型行为
360度多源评价：上下左右+自评
目标管理法(MBO)上下共同制定目标
平衡计分卡(BSC)4维度：财务/客户/内部流程/学习成长
评价者常见误差
晕轮效应近因效应中心化倾向 宽松/严格误差首因效应相似性误差
KPI vs OKR
维度KPIOKR
导向结果量化目标+关键成果
适用成熟业务、可量化创新业务、目标驱动
透明度部门内全公司公开

薪酬管理
🔴 高频 ★★★★★
真题年份
2017面2020笔2025笔2019面
薪酬结构
薪酬→ 内在（非经济）+ 外在（经济）
  • 外在薪酬 = 基本薪酬 + 可变薪酬 + 福利
  • 内在薪酬 = 工作保障、晋升、挑战性工作、培训机会等
4种薪酬模式
模式依据适用
以岗位岗位价值组织稳定、岗位明确
以能力知识技能潜力技术/研发岗位
以绩效工作产出营销、可量化岗
以市场劳动力供求紧缺关键人才
传统薪酬设计6原则
公平性竞争性激励性 认可性平衡性战略性
战略薪酬管理 vs 传统
  • 传统：内部公平 → 战略：外部市场敏感性
  • 传统：定期加薪 → 战略：可变薪酬（绩效驱动）
  • 传统：个人贡献 → 战略：团队贡献
  • 传统：工作保障 → 战略：就业能力
岗位评估方法
要素计点法（最精确）排序法 分类法因素比较法海氏系统
海氏系统：技能（专业知识）+ 解决问题能力 + 职务责任 → 3类岗位：上山型/平路型/下山型

招聘与录用
🔴 高频 ★★★★★
真题年份
2016面2017面2021笔
招聘流程
制定计划→ 发布信息→ 初步筛选→ 测试/面试→ 录用决策
内部 vs 外部招聘
维度内部招聘外部招聘
成本低高
激励员工晋升动力强引入新思维
风险低高
适用填补中高级基层/稀缺岗位
选拔测试方法
  • 知识测试：考察记忆/专业知识（最简单）
  • 能力测试：GATB（9种职业倾向）
  • 性格测试：MMPI、16PF、自陈式/投射式
  • 工作样本：实际任务完成，效度高
  • 评价中心：LGD（无领导小组）、公文处理、角色扮演
面试提问方式
简单提问（破冰）递进提问（诱导式） 比较式提问举例提问（行为事件）客观评价
胜任力模型（2017年高频）
  • 冰山模型：水上（知识技能）→ 水下（价值观/特质/动机）
  • 构建流程：BEI访谈 → 编码分析 → 建立模型 → 验证
  • 用途：招聘/培训/绩效/薪酬/晋升全模块支撑

战略性人力资源管理
🔴 高频 ★★★★★
真题年份
2016笔2017笔2022笔2025案例
SHRM核心逻辑
企业战略→ HR战略→ HR实践→ 组织绩效
3大匹配理论
  • 纵向匹配：HR战略 与 企业经营战略对齐
  • 横向匹配：各HR模块（招/培/绩/薪）相互一致
  • 组织匹配：HR战略 与 组织文化/结构匹配
HR战略类型对应
企业战略对应HR侧重
成本领先效率导向、精简用人、绩效薪酬
差异化创新激励、高素质人才、技能薪酬
集中化专业深度、内部晋升
HRBP（2024年考）
  • 定义：嵌入业务的HR伙伴，将HR服务与业务需求直接对接
  • 三支柱模型：COE（专家中心）+ HRBP（业务伙伴）+ SSC（共享服务）
  • 能力要求：业务敏锐度 + HR专业 + 战略思维 + 影响力

激励理论
🔴 高频 ★★★★
真题年份
2017面2023面2025面
内容型理论（What）
理论核心层次
马斯洛需求层次5层需求从低到高生理→安全→社交→尊重→自我实现
赫茨伯格双因素保健/激励因素保健≠激励；激励→满意
麦克利兰需求成就/权力/亲和高成就者适合创业
ERG（Alderfer）存在/关系/成长可同时激活；挫折-退化
过程型理论（How）
  • 期望理论（Vroom）：激励=效价 × 期望 × 工具性
  • 公平理论（Adams）：比较投入/产出比；横向/纵向比较
  • 目标设置理论：明确+挑战性目标 → 高绩效；SMART原则
强化理论（行为主义）
正强化负强化惩罚消退
正强化（奖励期望行为）→ 效果最佳；变比例强化 → 最持久
工作特征模型（内在薪酬）
技能多样性任务同一性任务重要性 工作自主性反馈

人力资本理论
🟠 中频
  • 人力资本 = 体现在人身上的技能+知识+能力
  • 舒尔茨：人力资本是经济增长的核心投入
  • 人力资源特性：能动性、时效性、再生性、社会性
  • 人力资源管理：战略合作者 + 变革推动者 + 员工代言人 + 行政专家（Ulrich四角色）
🏛️
组织文化
🟠 中频
  • Schein三层次：人工制品（可见）→ 倡导价值（中层）→ 基本假设（深层）
  • 功能：凝聚、导向、激励、规范、辐射
  • 文化变革步骤：解冻 → 变革 → 再冻结（Lewin）
  • 组织文化 → 战略实施的软性支撑（2018年论述）
💻
数字化人力资源
🟠 中频（近年热点）
  • 数字化HR工具：HRIS（信息系统）、人才测评、AI辅助招聘
  • 大数据应用：人员流失预测、绩效分析、培训推荐
  • AI对HR的影响：自动化简历筛选、面试辅助、个性化培训
  • 数字化转型挑战：数据安全、员工抵触、技能升级
  • HRBP在数字化中：从事务性 → 战略性角色转变
🎁
福利管理
🟠 中频
  • 法定福利（强制）：五险一金（养老/医疗/失业/工伤/生育+住房公积金）
  • 非法定：补充医疗、带薪休假、员工持股、弹性工作
  • 弹性福利计划（自助餐式）：员工自选福利项目
  • 优点：个性化、满意度高；缺点：管理复杂、成本高
🚀
职业生涯管理
🟠 中频
  • 超级职业生涯：不受组织边界限制，个人自主发展
  • 职业生涯4阶段：探索→建立→维护→衰退
  • 双通道：管理序列 + 技术序列（防止彼得原理）
  • 组织责任：提供资源/机会；个人责任：自我管理
  • 职业发展通道设计（2019年面试考）
📈
人才盘点与继任
🟠 中频
  • 九宫格矩阵：X轴绩效 × Y轴潜力 → 9类人才分类
  • 高绩效+高潜力 = 明星员工（重点培养）
  • 高绩效+低潜力 = 中坚员工（激励留用）
  • 低绩效+低潜力 = 问题员工（辅导或淘汰）
  • 继任计划：识别关键岗位 → 建立后备池 → 加速发展

易混概念对比表
复试必背
概念A概念B核心区别记忆口诀
绩效管理 绩效评价 管理=持续循环（计划→辅导→评价→反馈）；评价=结果测量的一个环节 管理是过程，评价是节点
战略薪酬 传统薪酬 战略薪酬以外部竞争力+可变薪酬为核心；传统薪酬以内部公平+固定薪酬为核心 传统固内部，战略活外部
KPI OKR KPI量化结果考核；OKR目标+关键成果+公开透明，侧重方向对齐 KPI量化，OKR方向
任务绩效 关系绩效 任务绩效=核心工作职责；关系绩效=OCB（公民行为），如助人、主动承担 任务=职责，关系=情义
保健因素 激励因素 保健因素（薪酬/环境）缺少→不满，增加→无满意；激励因素（成就/认可）增加→满意 保健去不满，激励出满意
内部招聘 外部招聘 内招：成本低、激励现有员工、文化连续；外招：引入新思维、人才更广 内稳外新
工作描述 工作规范 工作描述=工作做什么（职责职能）；工作规范=人要具备什么（任职资格） 描述说岗位，规范说人
HRBP 传统HR HRBP嵌入业务，战略性；传统HR事务性、职能型 HRBP入业务，传统HR做事务
岗位薪酬 能力薪酬 岗位薪酬看职位价值，稳定；能力薪酬看个人技能，宽带结构 岗定职位，能定人
