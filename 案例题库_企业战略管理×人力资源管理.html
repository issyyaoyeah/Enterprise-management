📋 案例背景

H公司是一家以汽车零部件制造为主业的中型企业，2015—2018年间实施激进的多元化扩张战略，先后进入新能源电池、工程机械、房地产三个不相关领域。集团总部对各子公司实施统一的人事政策：沿用汽车制造行业的绩效考核体系和固定薪酬结构，所有新业务的中高层管理岗位优先从内部提拔，招聘预算统一压缩。

📝 标准答案要点
▶ 展开完整参考答案
问题一：战略分析
  1. 战略类型判断：H公司实施的是不相关多元化战略（进入汽车制造的非相关行业）。不相关多元化缺乏行业间协同效应（无相关性的范围经济），仅能在财务层面分散风险，但无法将核心能力迁移到新业务。
  2. 战略分析缺失：公司在进入新业务前未充分运用SWOT/价值链分析，未识别自身核心竞争力（精密制造）无法在电池、房产等行业发挥作用。
  3. 结构未随战略调整：钱德勒命题指出"结构跟随战略"——H公司新业务沿用旧组织结构和管理体制，是战略实施的根本障碍。
  4. 结论：根本原因是战略制定阶段的资源能力高估 + 战略实施阶段的组织与人才支撑缺失。
问题二：HR纵横匹配分析
  1. 纵向匹配（Vertical Alignment）失败：HR战略应与企业战略方向一致。新能源电池需要创新型人才策略（柔性绩效、宽带薪酬），房地产需要市场型人才策略，但公司实施统一的制造业策略，纵向匹配完全断裂。
  2. 横向匹配（Horizontal Alignment）失败：新业务招聘（内部提拔）+ 绩效（制造指标）+ 薪酬（固定结构）三模块之间方向一致但方向错误，形成"协调的错误"。
  3. 人力资源规划缺失：未对新业务进行人才需求预测（德尔菲法/回归分析），供给预测（技能清单/马尔科夫矩阵），导致结构性人才缺口无法识别和弥补。
  4. 改进方案：① 针对不同业务单元制定独立的HR战略（成本型/创新型/市场型）；② 新业务核心岗位优先外部招募；③ 各业务绩效指标与其战略目标对齐；④ 引入宽带薪酬适配创新业务需求；⑤ 建立战略性人才储备机制。

问题一：培训需求分析三层次
  1. 组织层次：战略目标（线上40%）与当前能力（线上5%）存在巨大差距，数字化转型是组织层面的核心培训驱动；组织文化（传统零售思维）与新战略冲突，需要文化变革培训。
  2. 任务/工作层次：数字化运营岗位需要的KSA——手机端系统操作（技能）、线上客户服务（能力）、数据分析基础（知识）均存在缺口；"到家业务"要求员工掌握路线规划、实时沟通等新技能。
  3. 个人层次：1200名一线员工几乎全部存在数字技能缺口（系统使用率仅12%为证）；中层管理者存在"意愿"缺口（不是不会，而是抵触），需要认知转变而非技能培训。
  4. 培训方案建议：分层设计——基层侧重操作技能（OJT现场实操）；中层侧重数字化管理理念（研讨会+案例）；新引进互联网人才侧重文化融入（导师制）。

问题一：人员过剩分流方案（颜P140-142）

人员过剩处理原则：提前预警、分类安置、依法合规、人文关怀。六种过剩处理方式：

  1. 自然减员：对45岁以上员工可适用提前退休/内退政策（符合劳动法），引导部分人自愿离开
  2. 内部转岗：对技能可转移的文旅人员优先考虑转入化工辅助岗位（行政、后勤、安全管理）
  3. 协议解除：给予高于法定标准的经济补偿金，与员工协商解除劳动合同
  4. 随业务转移：被剥离文旅业务整体出售时，相关员工随业务转移至新主体（需获员工同意）
  5. 再培训再就业：对有意愿转型的员工，提供职业技能培训补贴
  6. 保留弹性用工：对部分岗位转为劳务合同或外包，降低固定用工风险

合规提示：国有企业大规模裁员须提前通知工会，按《劳动合同法》第41条执行经济性裁员程序，需向劳动行政部门报告。
